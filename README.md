# Automatic Earthquake Declustering

Code for **Automatic Earthquake Declustering with the Susceptibility Index**. The main tool selects a nearest-neighbor similarity threshold from the Susceptibility Index (SI) curve and labels earthquakes as background or triggered events. A separate ETAS program is intended to evaluate declustering on simulated catalogs with known parent relationships.

## Tools and where to start

| Tool | Purpose | Guide | Current status |
| --- | --- | --- | --- |
| Susceptibility Index tool | Classify a four-column earthquake catalog; export SI and nearest-neighbor diagnostics | [Declustering guide](Susceptibility%20Index/Susceptibility%20Index%20tool/README.md) | Builds with GNU Fortran; rerun it before using the results with the current plots |
| `fig_1.py` | Plot rescaled nearest-neighbor distances, the selected threshold, SI, and a nearest-neighbor histogram | [Plotting instructions](Susceptibility%20Index/Susceptibility%20Index%20tool/README.md#plots) | Requires results generated by the current Fortran source |
| `fig_2.py` | Compare the input and background catalogs over time, with cumulative event counts | [Plotting instructions](Susceptibility%20Index/Susceptibility%20Index%20tool/README.md#plots) | Expects catalog times in seconds |
| `cat10_to_cat4.f90` | Convert calendar timestamps and earthquake coordinates to a four-column catalog | [Converter guide](Preprocess_tools/README.md) | Builds with GNU Fortran; output coordinate order matches SI input |

The Fortran programs use paths and parameters defined in source files; they have no command-line options. Recompile after changing those values.

## Requirements

- GNU Fortran (`gfortran`) for catalog conversion and declustering.
- Python 3 with NumPy, pandas, Matplotlib, and SciPy for plots and the Python examples.
- A shell that can run the commands below. Bash examples work on Linux/macOS or an appropriately configured WSL environment; PowerShell examples are supplied for native Windows.

## Quickstart: decluster the included catalog

The supplied `datasets/input_catalog.txt` is already a copy of the Southern California catalog. It has 43,062 rows; the default `mcut = 3.0` retain 12,767 events. 

Run from the repository root in Bash:

```bash
cd "Susceptibility Index/Susceptibility Index tool"
mkdir -p results
gfortran -O3 global_parameters.f90 main_program.f90 randgen.f -o susceptibility.out
./susceptibility.out
cd plots
python fig_1.py
python fig_2.py
```

Or in PowerShell:

```powershell
Set-Location 'Susceptibility Index/Susceptibility Index tool'
New-Item -ItemType Directory -Force -Path results | Out-Null
gfortran -O3 global_parameters.f90 main_program.f90 randgen.f -o susceptibility.exe
.\susceptibility.exe
Set-Location plots
python fig_1.py
python fig_2.py
```

Each run replaces the four output files in `results/`; save previous results if you need to compare runs. Both plotting scripts also replace their PNG files. Run the executable from the tool directory and the plotting scripts from `plots/`, because their paths depend on the working directory.

## Use your own catalog

1. Prepare a headerless, whitespace-separated catalog in ascending time order, with columns `elapsed_time_seconds latitude_degrees longitude_degrees magnitude`. 
2. Replace `Susceptibility Index/Susceptibility Index tool/datasets/input_catalog.txt`, or change `input_file` in that tool's `global_parameters.f90`.
3. Set `mcut`, `bval`, `df`, and the threshold scan parameters for your dataset; then recompile and run. Only positive-time events with magnitude at least `mcut` are retained. 
4. Inspect the SI curve and selected threshold, then use column 5 of `results/output_catalog.txt`: **0 = background**, **1 = triggered**. The [declustering guide](Susceptibility%20Index/Susceptibility%20Index%20tool/README.md#extract-the-background-catalog) includes an extraction example and exact output schemas.

Calendar-date catalogs can be prepared with the [converter](Preprocess_tools/README.md). Its output uses the SI coordinate order. 

## Included data and supporting files

- `Data/Southern California/sc_conv_1-1-1981_31-3-2022.txt`: four-column Southern California catalog for 1981-01-01 through 2022-03-31. See [catalog metadata](Data/Southern%20California/readme.txt) for the origin time, region, and source.
- `Data/Simulations/Southern California/Background coordinates/`: two six-column coordinate pools, also copied into the ETAS `datasets/` directory with `.dat` extensions. Their coordinate convention needs reconciling with ETAS before use; see its guide.
- `randgen.f`: supporting random-number routines, duplicated in both tool directories. ETAS uses its Poisson generator; SI does not call its routines.
